# Laurelhurst Geo File

These are the files collected to initialize the Laurelhurst neighborhood

## `raw/`

These files were converted to geojson from shapefiles using https://gis.tools/shapefile-to-geojson.

The original shapefiles were collected as part of the UW resilience project.

### `cluster_map_v8.geojson`
Contains the cluster polygons and names.

Rename to `clusters.geojson`

### `filtered_POIs.geojson`
Contains the points of interest.

Rename to `points-of-interest.geojson`

Updated each feature to add a `type` that maps to school, church, etc.

### `laurelhurst_address_recoded_2020_parcel.geojson`
Contains the households.

Rename to `households.geojson`
